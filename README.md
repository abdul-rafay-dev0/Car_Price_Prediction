# 🚗 Car Price Prediction

A Machine Learning mini-project designed to predict car prices based on various features (e.g., year, mileage, brand, fuel type) using **Linear Regression**. This project demonstrates a complete end-to-end ML pipeline, from raw data cleaning to model evaluation.

## 📌 Project Overview
The goal of this project is to build a robust predictive model that estimates the market value of a car. By applying rigorous data preprocessing and feature engineering techniques, the model learns the underlying patterns that drive vehicle pricing.

## 🔑 Key Features
- **Exploratory Data Analysis (EDA):** Visualized distributions and correlations to understand feature impact.
- **Data Preprocessing:** Handled missing values, removed outliers, and scaled numerical features.
- **Feature Engineering:** Applied One-Hot Encoding for categorical variables to make them model-ready.
- **Model Evaluation:** Assessed performance using **R²** and **Adjusted R²** to ensure the model generalizes well to unseen data.

## 🛠️ Tech Stack
- **Language:** Python
- **Data Manipulation:** Pandas, NumPy
- **Machine Learning:** Scikit-Learn (`LinearRegression`, `train_test_split`, `StandardScaler`)
- **Visualization:** Matplotlib, Seaborn

## 📊 Dataset
The dataset contains historical car sales data with features such as:
- `Year`, `Mileage`, `Brand`, `Fuel_Type`, `Engine_Size`, and `Price` (Target Variable).
